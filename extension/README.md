# ygo-th extension (v2)

แสดงคำแปลภาษาไทยของข้อความการ์ดบน Dueling Nexus จากฐานคำแปล ygo-th — **ไม่มี AI ในตัว** ไม่ต้องติดตั้งอะไรเพิ่ม

## ติดตั้ง (Edge / Chrome 137+)
1. ดาวน์โหลดโฟลเดอร์ `extension/` นี้
2. เปิด `edge://extensions` (หรือ `chrome://extensions`) → เปิด Developer mode
3. Load unpacked → เลือกโฟลเดอร์ `extension`
4. คลิกไอคอน extension → **อัปเดตตอนนี้** (ครั้งแรกโหลดเองอัตโนมัติ หลังจากนั้นเช็กทุก 12 ชม.)

## ทำงานอย่างไร
- โหลด `v1/manifest.json` → ตรวจลายเซ็น Ed25519 กับกุญแจที่ฝังใน `background.js` → เวอร์ชันต้องใหม่กว่าที่มี
- โหลด `all.json.gz` → ตรวจขนาด + sha256 ตาม manifest → เก็บใน IndexedDB (เปลี่ยนทั้งก้อนใน transaction เดียว)
- ถ้าขั้นไหนไม่ผ่าน จะใช้ฐานเดิมต่อและแสดงข้อผิดพลาดใน popup
- บนหน้าเว็บ: อ่าน passcode จาก `#card-id` แล้วแสดงคำแปล (สร้าง DOM ด้วย textContent เท่านั้น) พร้อมป้าย
  ✓ ตรวจแล้ว / 👥 ชุมชน / 🤖 AI · ⚠ อาจเก่า (ข้อความอังกฤษไม่ตรงกับ `en_sha256`) · ยังไม่มีคำแปล
- ไม่ส่งข้อมูลใด ๆ ออกไป นอกจากดาวน์โหลดไฟล์จาก GitHub Pages ลิงก์ "แจ้งแก้" เปิดหน้า issue บน GitHub ให้ผู้ใช้กรอกเอง

## การจัดรูปแบบคำแปล (format.js)
จัดเหมือนที่ Dueling Nexus จัดภาษาอังกฤษ และใช้สีชุดเดียวกับเว็บ
- แยกเป็นบล็อกมีเว้นวรรค: ตามบรรทัด, ตามจุด `. ` และตามจุดเริ่มเอฟเฟกต์ใหม่ (คำว่า ถ้า / เมื่อ / ในช่วง / 1 ครั้งต่อเทิร์น / คุณสามารถ …) ใช้กับประโยคที่ AI ไม่ได้ใส่จุดไว้
- เงื่อนไข (ก่อน `:`) สีเหลือง · cost (ระหว่าง `:` กับ `;`) สีชมพู · เงื่อนไขการอัญเชิญ สีฟ้า
- "ชื่อการ์ด" ตัวเอียง · ข้อจำกัดการใช้ (… 1 ครั้งต่อเทิร์น) ขีดเส้นใต้ · Quick Effect ตัวหนา
- ใช้ตัวช่วยเดาจุดแบ่งเอฟเฟกต์ จึงแบ่งผิดได้บ้างในใบที่ประโยคซับซ้อน แต่ข้อความจะไม่หายหรือเปลี่ยน (ทดสอบกับทุกใบในฐานแล้ว)

## เปลี่ยนกุญแจ
ถ้ารัน `tools/keygen.mjs` ใหม่ ต้องแก้ `PUBLIC_KEY_B64` ใน `background.js` ให้ตรงกับ `keys/ygo-th.pub.pem` แล้วออกเวอร์ชันใหม่
