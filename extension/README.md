# ygo-th extension (v2)

แสดงคำแปลภาษาไทยของข้อความการ์ดบน Dueling Nexus จากฐานคำแปล ygo-th — **ไม่มี AI ในตัว** ไม่ต้องติดตั้งอะไรเพิ่ม

## ติดตั้ง (Edge / Chrome 137+)
1. ดาวน์โหลด `ygo-th-extension-X.Y.Z.zip` จาก [Releases](https://github.com/prachpawee-tang/ygo-th/releases) แล้วแตกไฟล์ไว้ในโฟลเดอร์ที่จะไม่ลบ
2. เปิด `edge://extensions` (หรือ `chrome://extensions`) → เปิด Developer mode
3. Load unpacked → เลือกโฟลเดอร์ที่แตกไว้ (ที่มี `manifest.json`)
4. คลิกไอคอน extension → ดูว่าฐานคำแปลโหลดแล้ว (ครั้งแรกโหลดเองอัตโนมัติ ถ้ายังไม่ขึ้นกด **อัปเดตตอนนี้** · หลังจากนั้นเช็กเองทุก 12 ชม.)

ทดสอบโค้ดที่แก้ในเครื่อง: Load unpacked โฟลเดอร์ `ygo-th\extension` ตรง ๆ แล้วกดรีโหลด (↻) ทุกครั้งที่แก้ไฟล์

## ทำงานอย่างไร
- โหลด `v1/manifest.json` → ตรวจลายเซ็น Ed25519 กับกุญแจที่ฝังใน `background.js` → เวอร์ชันต้องใหม่กว่าที่มี
- โหลด `all.json.gz` → ตรวจขนาด + sha256 ตาม manifest → เก็บใน IndexedDB (เปลี่ยนทั้งก้อนใน transaction เดียว)
- ถ้าขั้นไหนไม่ผ่าน จะใช้ฐานเดิมต่อและแสดงข้อผิดพลาดใน popup
- **หาไม่เจอด้วยเลข → หาด้วยชื่อการ์ด (2.3.1):** Dueling Nexus ใช้เลขของตัวเองกับภาพการ์ดแบบอื่น (เช่น Brain Control ขึ้น `87910998` แต่ passcode จริง `87910978`) และการ์ดใหม่ที่ยังไม่มีเลขจริง → ใช้ชื่อภาษาอังกฤษจาก `#card-name` แทน (เช็ก "อาจเก่า" ด้วยข้อความอังกฤษเหมือนเดิม) และลิงก์แจ้งแก้ส่ง passcode จริง
- บนหน้าเว็บ: อ่าน passcode จาก `#card-id` แล้วแสดงคำแปล (สร้าง DOM ด้วย textContent เท่านั้น) พร้อมป้าย
  ✓ ตรวจแล้ว / 👥 ชุมชน / 🤖 AI · ⚠ อาจเก่า (ข้อความอังกฤษไม่ตรงกับ `en_sha256`) · ยังไม่มีคำแปล
- **แจ้งเตือนเวอร์ชันใหม่ (2.2.0):** เช็ก GitHub Releases (tag `ext-vX.Y.Z`) ไม่เกินชั่วโมงละครั้ง ถ้ามีใหม่ขึ้นป้าย NEW บนไอคอน และลิงก์ดาวน์โหลดใน popup
- **"แจ้งแก้คำแปล" (2.3.0):** เปิด **Google Form** (ไม่ต้องมีบัญชีใด ๆ) โดยกรอก passcode, ชื่อการ์ด และคำแปลปัจจุบันไว้ให้ ผู้ใช้แก้เฉพาะจุดที่ผิดแล้วกดส่ง · ลิงก์ **(GitHub)** ข้าง ๆ สำหรับคนที่มีบัญชี เปิด issue แบบเดิม (2.2.0)
- ไม่ส่งข้อมูลใด ๆ ออกไป นอกจากดาวน์โหลดไฟล์จาก GitHub Pages และอ่านรายการ Release จาก api.github.com · ลิงก์ "แจ้งแก้" แค่เปิดหน้า Google Form / GitHub ในแท็บใหม่ ผู้ใช้กดส่งเอง

## การจัดรูปแบบคำแปล (format.js)
จัดเหมือนที่ Dueling Nexus จัดภาษาอังกฤษ และใช้สีชุดเดียวกับเว็บ
- แยกเป็นบล็อกมีเว้นวรรค: ตามบรรทัด, ตามจุด `. ` และตามจุดเริ่มเอฟเฟกต์ใหม่ (คำว่า ถ้า / เมื่อ / ในช่วง / 1 ครั้งต่อเทิร์น / คุณสามารถ …) ใช้กับประโยคที่ AI ไม่ได้ใส่จุดไว้
- เงื่อนไข (ก่อน `:`) สีเหลือง · cost (ระหว่าง `:` กับ `;`) สีชมพู · เงื่อนไขการอัญเชิญ สีฟ้า
- "ชื่อการ์ด" ตัวเอียง · ข้อจำกัดการใช้ (… 1 ครั้งต่อเทิร์น) ขีดเส้นใต้ · Quick Effect ตัวหนา
- ใช้ตัวช่วยเดาจุดแบ่งเอฟเฟกต์ จึงแบ่งผิดได้บ้างในใบที่ประโยคซับซ้อน แต่ข้อความจะไม่หายหรือเปลี่ยน (ทดสอบกับทุกใบในฐานแล้ว)

## เปลี่ยนกุญแจ
ถ้ารัน `tools/keygen.mjs` ใหม่ ต้องแก้ `PUBLIC_KEY_B64` ใน `background.js` ให้ตรงกับ `keys/ygo-th.pub.pem` แล้วออกเวอร์ชันใหม่
